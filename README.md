# jm_se

Material Design 3 风格的漫画阅读 Android 应用（Kotlin + Jetpack Compose）。

- 🎨 Material Design 3 + 动态取色，支持多种主题色
- 🎮 MIUI 风格（Miuix 组件库）一键切换
- 📚 首页 / 分类 / 搜索 / 我的 四大模块
- ⭐ 收藏、阅读历史、屏蔽（长按菜单）
- 📥 离线缓存（多 CDN 线路可切换）
- 💾 数据导出 / 导入（JSON 备份）
- 🚫 无广告、无游戏/电影等无关模块

## 构建

需要 JDK 21、Android SDK（compileSdk 36）。

```bash
./gradlew assembleDebug
```

APK 输出：`app/build/outputs/apk/debug/app-debug.apk`
